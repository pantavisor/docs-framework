### Note (context, not a table finding)

`classes/pvbase.bbclass:9` declares the default token `rngdaemon`, but the only `bb.utils.contains('PANTAVISOR_FEATURES', …)` gate referencing this feature checks the token `rngd` (`recipes-pv/images/pantavisor-initramfs.bb:34`), not `rngdaemon`. No gate anywhere in the repo checks the literal string `rngdaemon`. This means the token as spelled in the default list and mirrored faithfully by both docs pages may not actually gate `rng-tools` inclusion — a source-internal token-spelling inconsistency, not a docs error (docs correctly describe what `pvbase.bbclass` declares). Flagging for human triage since it affects whether `rngdaemon` is genuinely load-bearing.

`conf/distro/*.inc` layers `:append`/`:remove` modifiers on top of the base default (`panta-distro.inc` appends `pv-manifest-audit`; `panta-appengine.inc` appends `appengine`+`pv-manifest-audit` and removes `autogrow`) — noted as context, not treated as a mismatch source since it changes the effective default per distro without changing the documented base default.
